# Luna Moda

Loja feita com HTML, CSS e JavaScript, sem frameworks ou servidor. A entrega está disponível somente em Manaus e Iranduba. Os arquivos principais são:

- `index.html`: estrutura da página.
- `style.css`: visual responsivo e banner com profundidade 3D.
- `script.js`: vitrine, busca, sacola e envio do pedido.
- `catalog.js`: dados dos 70 produtos.

Abra `index.html` no navegador. As fotos do banner e dos produtos vêm do Unsplash e precisam de internet.

## Pedidos e pagamento

O cliente informa os dados de entrega, escolhe dinheiro ou Pix na entrega e envia o pedido pelo WhatsApp da loja. O Pix é combinado e pago na hora da entrega; não há cobrança online. Confirme o frete, o prazo e a disponibilidade com o cliente pelo WhatsApp.

No começo de `script.js`, troque `WHATSAPP_NUMBER` pelo número da loja com código do país e DDD, somente dígitos. Exemplo: `5511999999999`.
